First release of OEPS KiCad Production Files for Windows x64.

## Included

- Check and repair Symbol Fields Table fields, grouping, export format, field order, revision, and PCB Gerber plot settings. Each repair requires its own confirmation and saves a backup.
- Generate Gerber files, placement CSV with component count, separate Excellon PTH/NPTH drills with Gerber X2 maps, and an IPC-D-356 netlist.
- Select exports independently and optionally clear manufacturing before generation. A Gerber reminder asks you to check zone fills and included layers first.
- Refresh the shared OEPS component database every five minutes.
- OEPS launcher, installer and versioned update packages with SHA-256 checksums.

## Installation

Download `Oeps.KicadProductionFiles-0.1.0-setup-win-x64.zip`, extract it completely and run `Install.cmd`. The installer checks for the .NET 10 Desktop runtime and offers installation if needed. Select your installed `kicad-cli.exe` and project folder in the GUI.

The smaller `Oeps.KicadProductionFiles-0.1.0-win-x64.zip` is the application update package. Both ZIPs have separate `.sha256` files.

## Known limitations

- Use **KiCad 10.0.6 or later for IPC-D-356 exports**. KiCad 10.0.3 can emit invalid solder-mask values for vias. This release checks the netlist header and end marker, but does not detect those invalid field values. Regenerate affected files with the corrected KiCad version before production.
- The release repository is private. Downloading release assets requires repository access. The current launcher uses unauthenticated GitHub requests, so automatic update discovery is unavailable while the repository is private; install future setup packages manually.
- BOM export, BOM/placement quantity comparison and component identifier validation are not implemented yet.
- Export validation checks basic file format and presence; it does not certify board geometry or manufacturing correctness.

## Verification

162 automated tests passed. The Windows GUI and Gerber, placement, drill/map and IPC-D-356 exports were exercised using isolated sample boards with KiCad CLI 10.0.3. The known via-field defect was subsequently confirmed against real output and KiCad source. The corrected KiCad 10.0.6 exporter was inspected in source; it has not been run locally.
