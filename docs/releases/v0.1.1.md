OEPS KiCad Production Files for Windows x64.

- Install with a per-user MSI that bundles the .NET 10 runtime. Desktop and Start-menu shortcuts open the launcher directly, following Raw Material Sticker's installation architecture. Existing preferences, database cache and app version history are preserved.
- Improved DPI scaling, screen fitting and scrolling across the main window, launcher and update dialog.
- Added numeric revisions and a read-only check for the expected revision on PCB silkscreen. The revision hint now shows `e.g. RevB, B, ver1.3, v1.3.2, 1.3.2`.
- Generate the BOM first using the saved Symbol Fields Table settings. Report component counts and BOM/placement differences, with a popup when counts differ.
- Check required BOM fields, compare BOM values with the database, and compare the BOM with PCB footprints. All three tests validate OEPS PN, MPN and OEPS Description and have descriptive report names.
- Check identifiers and descriptions before generation using a temporary CLI BOM of the complete schematic hierarchy and the existing five-minute database cache.
- Configure files can fill or correct schematic OEPS Description when OEPS PN and MPN match a database pair. Review changes in a scrollable Yes/No confirmation. Changed sheets are backed up and checked again; invalid pairs remain unchanged.
- Added green check/red cross markers and an overall result at the top of reports.
- Simplified the Gerber reminder to zone fills, Include Layers and saving the board; PCB revision is checked separately.

Download and run **Oeps.KicadProductionFiles-0.1.1-setup-win-x64.msi**, including over an older ZIP-based installation. The smaller **Oeps.KicadProductionFiles-0.1.1-win-x64.zip** is the app update package. Both assets include SHA-256 checksum files. Windows uninstall preserves preferences and app version history. The installer is unsigned.

Validation includes 229 automated tests, real KiCad CLI exports, GUI checks, and a description-fix trial on an isolated four-sheet project. Save changes in KiCad before checking or generating files, and reopen edited schematics after applying fixes.

The KiCad IPC-D-356 via-field limitation documented in the [v0.1.0 release notes](https://github.com/oeps-tech/generate-kicad-production-files/releases/tag/v0.1.0) still applies; this release does not change KiCad's exporter.
